Internship Experience Context - Logicwind

During my summer internship at Logicwind, I got the opportunity to work in a professional backend development environment and understand how real-world software systems are planned, developed, reviewed, and delivered. This internship is planned for six months in total. At the time of preparing this report, I have completed the first month of the internship and the remaining five months are still ongoing. During this first completed month, my main focus was on strengthening backend fundamentals, understanding production-level project structure, and learning how teams manage tasks using tools like ClickUp. I learned how work is divided into tasks, assigned with priorities, tracked through different stages, and reviewed by seniors before completion.

A major part of my learning was focused on backend development, where I explored how APIs are designed, how request-response flow works, and how different layers such as routes, controllers, services, models, validations, and database operations are organized. I worked with technologies such as Node.js, Express.js, TypeScript, PostgreSQL, Sequelize, GraphQL, and Apollo Server. Through these tools, I understood how backend systems are made scalable, maintainable, and modular by following proper folder structure, clean service logic, and separation of concerns.

I also learned important backend security practices that are required in real applications. This included concepts like authentication, authorization, JWT-based access control, password hashing, input validation, error handling, rate limiting, secure API design, and middleware-based protection. While working with GraphQL and Apollo Server, I understood how GraphQL differs from REST APIs, how schemas and resolvers are created, how queries and mutations work, and how security must be handled carefully to avoid issues such as over-fetching, unauthorized access, and malicious queries.

One of the important projects I worked on during the internship was the EcoRoute Engine / EcoRoute System, which focuses on building a backend system for route planning, vehicle management, pickup management, dispatch operations, drivers, organizations, users, audit logs, and related modules. Through this project, I learned how to design backend APIs for a real-world logistics or waste-management type platform. It helped me understand database relationships, API endpoint planning, role-based functionality, and how different business modules communicate with each other inside a backend system.

Apart from technical development, I also learned how professional teams collaborate using tools like ClickUp, Git, GitLab/GitHub, issue tracking, code reviews, and daily task updates. ClickUp helped me understand how tasks are documented, how deadlines are managed, how progress is tracked, and how developers communicate blockers or updates with seniors. This improved my understanding of professional workflow, team communication, responsibility handling, and disciplined development practices.

Overall, the first month of my internship helped me build a strong foundation in backend engineering and gave me practical exposure to production-level development. I learned not only how to write backend code, but also how to think about system design, security, database structure, API planning, documentation, debugging, and teamwork. Since five months of the internship are still remaining, this report represents an interim learning stage rather than the final completion of the full internship. This experience has already been valuable and will help me improve further in the upcoming months as I continue working on backend projects and real-world development tasks.
